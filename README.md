# NEON RAAT

An original procedural third-person Indian nightlife prototype built with Ursina.
It uses no third-party art or music assets; the exterior, interior, NPCs, and
short background audio loops are generated by the project.

## Linux installation

Python 3.10+ and a working desktop/OpenGL driver are recommended.

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

The first launch synthesizes original WAV loops and effects under
`user_data/audio/`. Wallet balance and purchase history are saved to
`user_data/wallet.json`. These files are local game data and may be removed to
reset the wallet or regenerate audio.

## Controls

- **W / A / S / D**: move
- **Left Shift**: sprint
- **E**: interact with the nearby entrance, NPC, bar, stage, or lounge gate
- **1–9**, **Up / Down**, **Enter**, or mouse click: select menu options
- **Escape**: close a menu; when no menu is open, quit
- **H**: show recent wallet transactions
- **M**: music/effects volume and mute settings

Approach reception outside the entrance and interact to purchase entry. Entry
unlocks are saved and do not charge repeatedly. VIP and private lounge purchases
are separate access entitlements. Prices: normal entry ₹500, VIP entry ₹2,000,
private lounge ₹1,000, dance entertainment ₹300, refreshments ₹200.

## Tests

```bash
python -m unittest discover -s tests -v
```

The tests cover wallet persistence, purchase idempotency, insufficient funds,
malformed save handling, and write failures. Ursina scene smoke checks can also
be run using `Ursina(window_type="offscreen")` where a Panda3D graphics backend
is available.
